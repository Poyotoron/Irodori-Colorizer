# 設定

`Edit > Project Settings > Irodori Colorizer` で開きます。
ラベル一覧の下部にある **`設定…`** ボタンからも開けます。

変更はその場で保存され、Project ウィンドウと Hierarchy ウィンドウにすぐ反映されます。

## 表示

| 項目 | 説明 |
|---|---|
| 有効 | オフにすると色付けを完全に停止します。割り当ては保持されます |
| Project ウィンドウ | Project ウィンドウでの色付けをオン / オフします |
| Hierarchy ウィンドウ | Hierarchy ウィンドウでの色付けをオン / オフします |
| 行全体を塗る | オフにすると、アイコンと名前の周りだけを塗ります |
| 塗りの濃さ | 色の不透明度。薄くするほど、元の行の見た目が残ります |
| 選択行は塗らない | 選択中の行を塗らず、Unity の選択ハイライトを優先します |

!!! tip "色が主張しすぎると感じたら「塗りの濃さ」を下げてください"
    既定値でも十分に見分けられますが、行数が多いと画面が賑やかになります。
    濃さを下げると、色は分かるまま背景になじみます。

## ラベル表示

| 項目 | 説明 |
|---|---|
| 文字色を自動判定 | 塗った色の明るさに応じて、文字を白 / 黒へ自動で切り替えます |
| 文字色（固定） | 自動判定をオフにしたときに使う文字色 |
| ラベル位置 | 文字の描画位置の微調整。環境によって数ピクセルずれる場合に使います |

!!! note "黄色などの明るい色でも文字が読めるのは、自動判定が働いているためです"
    自動判定をオフにして固定色を選ぶと、明るい色の行で文字が読みにくくなることがあります。

## プリセット

同梱するラベル束のオン / オフを切り替えます。各行に件数と 1 行の説明が付きます。
挙動は[プリセット](presets.md)を参照してください。

オフのプリセットに紐づく割り当てが残っている場合、その件数が案内として表示されます。
**放置して問題ありません。** プリセットを再びオンにすれば、そのまま復元されます。

「解決できないラベル ID の割り当て」という案内が出ることもあります。
これは削除済みの独自ラベルに紐づいていた割り当てです。表示上は無視され、実害はありません。

## ラベル一覧

有効なプリセットのラベルが、束ごとの見出し付きで並びます。各行で次の操作ができます。

| 表示 | 操作 |
|---|---|
| 色フィールド | ラベルの色を変更する |
| 名前フィールド | ラベルの名前を変更する |
| カラーコード | 選択してコピーできます |
| **◉** / **◎** | そのラベルを非表示 / 再表示する |
| **↺** | そのラベルを既定の色・名前に戻す |
| **×** | 独自ラベルを削除する（同梱ラベルには出ません） |

一覧の下に **`すべてのオーバーライドをリセット`** があります。
押すと、同梱ラベルに対して行った色・名前・非表示の変更が**まとめて既定値へ戻ります。**
確認ダイアログが出ます。独自ラベルと、どこに何を塗ったかの情報は消えません。

最下部の入力欄からは、カラーコードと名前を指定して独自ラベルを追加できます。

!!! warning "独自ラベルを削除すると、そのラベルを付けた行の色は消えます"
    割り当て自体は残りますが、参照先のラベルが無くなるため描画されません。
    削除時に確認ダイアログが出ます。

## 設定の保存先と共有

すべての設定と割り当ては `ProjectSettings/IrodoriColorizer.asset` に保存されます。
このファイルを Git で共有すれば、同じプロジェクトを開いた全員に同じ色が付きます。
