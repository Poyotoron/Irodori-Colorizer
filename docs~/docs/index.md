# はじめに

**Irodori Colorizer** は、Unity の Project ウィンドウと Hierarchy ウィンドウの行に
**色付きラベル**を付けるエディタ拡張です。

フォルダやオブジェクトが増えるほど、名前を目で追う時間は長くなります。
「衣装はピンク」「触ってはいけない配布物は茶色」と決めてしまえば、
探すより先に**色で目的地が分かります。**

## 色ではなく「ラベル」を付けます

このツールが扱う単位は、**色と名前がセットになったラベル**です。

単に色だけを塗ると、しばらく経ってから「この赤は何の赤だったか」が分からなくなります。
ラベルには名前が付いているので、意味が残ります。ラベルは色や名前を後から変更でき、
変更しても**すでに塗った行の割り当ては外れません。**

用途別のラベル一式（[プリセット](presets.md)）を同梱しているので、
自分で色を決めなくてもすぐ使い始められます。

## プロジェクトを汚しません

!!! success "シーンにもアバターにも、何も追加しません"
    このツールは、色を覚えておくためのコンポーネントを一切追加しません。
    色の情報はプロジェクト設定として `ProjectSettings/` に保存されるため、
    `Assets/` の中身は変化せず、**ビルドやアップロードの成果物にも影響しません。**

Editor 専用です。実行中（Play Mode）の挙動には一切関与しません。

## このツールがやること・やらないこと

| やること | やらないこと |
|---|---|
| Project / Hierarchy の行を色付きラベルで塗る | フォルダアイコンの画像そのものの差し替え |
| 用途別プリセットの提供と切り替え | 名前や型からの自動着色 |
| カラーコード（Hex）による独自ラベルの追加 | 実行時（Play Mode / ビルド後）への関与 |
| 移動・改名しても外れない色の記録 | シーンやアバターへのコンポーネント追加 |
