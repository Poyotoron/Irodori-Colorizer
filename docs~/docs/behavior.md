# 色の付き方

このページは「どこに色が記録されているか」の説明です。
色が消える条件と、Prefab の連動を理解するために読んでください。

## 色は「名前」ではなく「対象そのもの」に付きます

色は、フォルダ名やパスではなく、**対象を一意に指す内部の識別子**に記録されます。
記録先は対象の種類によって 2 種類あります。

| 対象 | 何にひも付くか | 移動・改名 |
|---|---|---|
| フォルダ、アセット全般 | アセットの固有 ID（GUID） | **色は外れません** |
| シーン上の Prefab インスタンスのルート | **元の Prefab アセット**の GUID | **色は外れません** |
| その他の GameObject | シーン上での識別子 | シーン内の移動では外れません |

!!! success "フォルダを整理し直しても、色は付いたままです"
    パスを見ていないため、フォルダを別の場所へ移しても、名前を変えても色は残ります。

## Prefab の色は Project と Hierarchy で共有されます

シーン上の Prefab インスタンスの色は、**元の Prefab アセットに付きます。**
そのため、どちら側から塗っても結果は同じになります。

| やったこと | 起きること |
|---|---|
| Hierarchy で Prefab インスタンスに色を付ける | Project の元アセットにも同じ色が付く |
| Project で Prefab アセットに色を付ける | シーン上のすべてのインスタンスにも同じ色が付く |
| どちらかで色を外す | もう一方からも消える（確認ダイアログが出ます） |

!!! note "これは同期処理ではなく、同じ情報を両方から見ているだけです"
    片方の色をもう片方へ複製する仕組みではないため、「片方だけ色が残る」という
    ずれが起きません。

入れ子になった Prefab では、**最も内側のインスタンスのルート**が対象になります。
Prefab の子オブジェクトには色は受け継がれません。

## シーンの保存が必要な場合

Prefab ではない普通の GameObject は、シーン上の識別子で色を覚えます。
この識別子は、**シーンが一度も保存されていないと確定しません。**

!!! warning "未保存のシーンでは、普通の GameObject に色を付けられません"
    この状態でラベルを設定しようとすると、コンソールに
    「シーンを保存してからラベルを設定してください」と警告が出て、色は付きません。
    **先にシーンを保存してから**操作してください。

    Prefab インスタンスのルートは元アセットの GUID を使うため、**未保存でも色を付けられます。**

## 色が消える・付かない条件

| 状況 | 色 |
|---|---|
| フォルダ / アセットを移動・改名した | 残ります |
| GameObject をシーン内で移動・改名した | 残ります |
| アセットを削除して、同じ名前で入れ直した | **消えます**（別のアセット扱いになるため） |
| GameObject を削除して作り直した | **消えます** |
| 別のシーンへコピー＆ペーストした（Prefab 以外） | **付きません**（コピー先は別のオブジェクトです） |
| プリセットをオフにした / ラベルを非表示にした | 一時的に消えます（戻せば復元されます） |
| 独自ラベルを削除した | 消えます（割り当ては残りますが描画されません） |

## 表示されない場所

- Prefab の編集モード（Prefab ステージ）で開いた中身には、シーン用の色は付きません。
- Project ウィンドウのアイコン（グリッド）表示では、セルに色が重なる形で表示されます。
  サムネイルと名前の位置は通常表示と変わりません。
