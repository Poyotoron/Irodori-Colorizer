# 困ったときは

## 右クリックしてもメニューに出ない

`Irodori Colorizer > Set Label…` は、Project ウィンドウでは**何か選択している**ときだけ有効になります。
何も選ばずに空白部分を右クリックした場合は選べません。

メニュー自体が見当たらない場合は、パッケージが正しく導入されていないか、
コンパイルエラーで読み込まれていない可能性があります。
Unity のコンソールにエラーが出ていないか確認してください。

## ラベルを選んでも色が付かない

順番に確認してください。

| 確認すること | 場所 |
|---|---|
| 「有効」がオンになっているか | 設定画面の「表示」 |
| 「Project ウィンドウ」「Hierarchy ウィンドウ」がオンになっているか | 同上 |
| 「塗りの濃さ」が極端に低くないか | 同上 |
| そのラベルが非表示になっていないか | 設定画面の「ラベル一覧」 |
| そのラベルのプリセットがオフになっていないか | 設定画面の「プリセット」 |

!!! warning "コンソールに「シーンを保存してから…」と出た場合"
    未保存のシーンでは、Prefab 以外の GameObject に色を付けられません。
    シーンを保存してから、もう一度ラベルを設定してください。
    詳しくは[色の付き方](behavior.md)を参照してください。

## ラベル一覧に何も出ない

プリセットがすべてオフになっています。設定画面の「プリセット」で、
使いたいものをオンにしてください。

## 色が急に消えた

| 心当たり | 説明 |
|---|---|
| プリセットをオフにした | ラベルごと非表示になります。オンに戻せば復元されます |
| ラベルを個別に非表示にした | 同上。設定画面の **◎** を押すと戻ります |
| 独自ラベルを削除した | 削除したラベルの色は戻りません |
| アセットを入れ直した | 別のアセット扱いになるため、色は引き継がれません |
| 設定ファイルを差し戻した | `ProjectSettings/IrodoriColorizer.asset` に全情報が入っています |

## 選択した行が見づらい

塗りの色と Unity の選択ハイライトが重なるためです。
設定画面の **「選択行は塗らない」** をオンにすると、選択中の行は塗られなくなります。

## 文字が読みにくい

「文字色を自動判定」がオフになっていないか確認してください。
オンにすると、明るい色の行では黒、暗い色の行では白に自動で切り替わります。

文字の位置が数ピクセルずれて見える場合は、「ラベル位置」で調整できます。

## Prefab の色を外したら、他のインスタンスからも消えた

仕様どおりの動作です。Prefab インスタンスの色は元のアセットに付いているため、
外すと Project の表示と、シーン上のすべてのインスタンスから消えます。
実行前に確認ダイアログが出ます。詳しくは[色の付き方](behavior.md)を参照してください。

## 設定画面に「割り当てが N 件あります」と出る

現在オフになっているプリセット、または存在しないラベルに紐づく割り当てが残っている、
という案内です。**そのままで問題ありません。** 前者はプリセットをオンに戻せば復元されます。

## チームで色が揃わない

色の情報は `ProjectSettings/IrodoriColorizer.asset` に入っています。
このファイルが共有されていない（Git の管理対象外になっているなど）と、
各自の環境で別々の状態になります。共有すれば全員に同じ色が付きます。

## それでも解決しない

再現手順を添えて、[GitHub の Issues](https://github.com/Poyotoron/Irodori-Colorizer/issues) へ報告してください。
Unity のバージョンと、コンソールに出ているメッセージがあると調査が早くなります。
