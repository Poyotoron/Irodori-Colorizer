# クイックスタート

導入したあと、最初の 1 回を回すまでの手順です。所要 1 分。

## 1. フォルダに色を付ける

1. Project ウィンドウで、色を付けたいフォルダを右クリックします。
2. **`Irodori Colorizer > Set Label…`** を選びます。
3. ラベル一覧が開くので、好きなラベルをクリックします。

クリックした瞬間に、そのフォルダの行が塗られます。

!!! tip "まずは「触るな」から試すのがおすすめです"
    インポートしたまま書き換えたくない配布物のフォルダに **触るな**（茶色）を付けておくと、
    それだけで事故が減ります。

## 2. Hierarchy でも同じことをする

シーンを開き、GameObject を右クリック → **`Irodori Colorizer > Set Label…`** です。
手順は Project ウィンドウとまったく同じです。

!!! warning "Prefab ではない GameObject に色を付けるときは、先にシーンを保存してください"
    未保存のシーンでは、オブジェクトを識別する情報が確定しないため色を付けられません。
    Prefab インスタンスのルートだけは、未保存でも色を付けられます。
    詳しくは[色の付き方](behavior.md)を参照してください。

## 3. まとめて付ける

複数の対象を選択したまま右クリックしてラベルを選ぶと、**選択したすべてに同じラベルが付きます。**

## 4. 色を外す

右クリック → **`Irodori Colorizer > Clear Label`** を選びます。
ラベル一覧の下部にある **`ラベルを外す`** ボタンからも同じことができます。

## 5. 自分の色を足す

ラベル一覧の下部にカラーコード（Hex）の入力欄があります。
`#FF00AA` のように入力して **`＋`** を押すと、その色のラベルが追加され、
そのまま選択中の対象に適用されます。
