# プリセット

**プリセット**は、用途別にまとめたラベルの束です。3 種類を同梱しています。
設定画面の「プリセット」から、束ごとにオン / オフを切り替えられます。

| プリセット | 件数 | 初期状態 | 向いている用途 |
|---|---|---|---|
| VRChat アバター改変 | 13 | **オン** | アバター改変プロジェクト |
| ベーシックカラー | 16 | **オン** | 意味を自分で決めたい場合 |
| 汎用 Unity プロジェクト | 12 | オフ | ゲーム制作など一般的なプロジェクト |

## VRChat アバター改変

アバター改変で実際によく使われるフォルダ分けを元にした分類です。
Project にも Hierarchy にも同じ粒度で使えます。

| ラベル | 想定される対象 |
|---|---|
| 改変作業中 | 編集中の Prefab Variant、作業用フォルダ |
| アバター素体 | 素体の配布物一式 |
| 衣装 | 衣装アセット |
| 改変パーツ | 髪・目・アクセサリなどの差し替え部品 |
| 小物・ギミック | 持ち物、トグルで出し入れするもの |
| システム | ごろ寝など、大きめの仕組み一式 |
| アニメーション | AnimationClip / Animator Controller |
| マテリアル | マテリアル、その複製 |
| テクスチャ | 画像素材 |
| シェーダー | シェーダー一式 |
| メニュー | メニュー関連、メニューアイコン |
| ツール | アバターに取り込まないエディタ拡張 |
| 触るな | インポートしたまま書き換え禁止の配布物 |

!!! tip "「改変作業中」と「触るな」はセットで使ってください"
    この 2 つは「編集してよい場所」と「触ってはいけない場所」の対比です。
    先にこの 2 色だけ塗っておくと、配布物を直接書き換えてしまう事故を防げます。

## ベーシックカラー

意味を持たせていない汎用の 16 色です。名前は色名そのもの
（Red / Orange / Amber / Yellow / Lime / Green / Emerald / Teal /
Cyan / Blue / Indigo / Violet / Magenta / Pink / Brown / Gray）。

意味を自分で決めたい場合は、この束のラベル名を書き換えて使うのが手軽です。

## 汎用 Unity プロジェクト

初期状態ではオフです。設定画面でオンにすると使えます。

Scenes / Scripts / Prefabs / Materials / Textures / Models /
Animations / Audio / Shaders / UI / Editor / ThirdParty の 12 種類。

## オン / オフの挙動

| 操作 | 起きること |
|---|---|
| プリセットをオフにする | そのラベルが一覧から消え、**描画も止まる** |
| オフにしたときの割り当て | **消えません。** 保持されたまま、表示だけが止まります |
| 再びオンにする | 元の色のまま、すべて復元されます |
| ラベルを個別に非表示にする | プリセットのオフと同じ扱い（割り当ては保持されます） |

!!! success "オフにしても、塗った内容は失われません"
    「使わないので一旦消したい」ときは、迷わずオフにして構いません。
    オフの状態で割り当てが残っている場合、設定画面にその件数が表示されます。
    削除を促すものではないので、そのままで問題ありません。

## 使わないラベルを整理する

- **束ごといらない** → プリセットをオフにする
- **数個だけいらない** → 設定画面の「ラベル一覧」で、そのラベルを個別に非表示にする
- **名前や色が好みでない** → 設定画面でその場で書き換える（[設定](settings.md)）
