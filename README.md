# Irodori Colorizer

Project ウィンドウと Hierarchy ウィンドウの行に色を付けて、目的のフォルダやオブジェクトを
探しやすくする Unity エディタ拡張です。フォルダ数やオブジェクト数が増えても、色で一目で
見分けられます。

- Editor 専用。ビルドやアップロードの成果物には一切影響しません。
- 特定の SDK に依存しない汎用ツールです。

[使い方ドキュメント](https://ghp.maaaaa.net/Irodori-Colorizer/)では、ラベルの付け方・プリセット・設定を詳しく説明しています。

## 特徴

- **Project / Hierarchy にラベル付け** — 右クリックから用途に合った色付きラベルを設定できます。
- **用途別のプリセット** — アバター改変向け、ベーシックカラー、汎用 Unity プロジェクト向けの
  ラベル束を選んで利用できます。
- **独自ラベルの追加** — カラーコード（Hex）を指定して、好みの色と名前のラベルを追加できます。
- **リネーム・移動に追従** — 色はパスではなく内部 ID（アセットの GUID / シーン上の識別子）に
  ひも付くため、フォルダやオブジェクトを移動・改名しても色が外れません。
- **プロジェクトに保存** — 設定は `ProjectSettings/` に保存され、Unity を再起動しても残ります。
  `Assets/` を汚さず、Git でチーム共有もできます。
- **Prefab の色を双方向で共有** — Hierarchy 上の Prefab インスタンスに色を付けると元アセットにも付き、
  Project で元アセットに色を付けるとシーン上のすべてのインスタンスにも同じ色が付きます。
- **見た目の調整** — 塗りの濃さ、行全体を塗るか、選択行を塗らないか、文字色の自動判定などを
  設定画面から変更できます。

## 動作環境

- Unity 2022.3 以降
- コンポーネントの追加やシーンの改変は行いません（フットプリントなし）。

## インストール

VPM（VCC / ALCOM）対応プロジェクトに、このパッケージを追加してください。
`Packages/manifest.json` に直接追加する場合は、リポジトリを取得してローカルパッケージとして
配置するか、リリースの zip を `Packages/` 配下へ展開します。

## 使い方

1. **Project** でフォルダやアセットを右クリック →
   `Irodori Colorizer > Set Label…` を選び、ラベルを選択します。
2. **Hierarchy** で GameObject を右クリック →
   `Irodori Colorizer > Set Label…` を選び、ラベルを選択します。
3. ラベルを外すときは `Irodori Colorizer > Clear Label` を選びます。

複数選択したままメニューを開けば、まとめて同じラベルを設定できます。
ポップアップ下部へカラーコード（Hex）を入力すると、独自の色を追加してそのまま適用できます。

> Prefab でない GameObject の色はシーン上の識別子にひも付きます。これらへ色を設定するときは、
> **シーンを一度保存してから**操作してください。Prefab インスタンスのルートは未保存シーンでも設定できます。

詳しい操作方法は[使い方ドキュメント](https://ghp.maaaaa.net/Irodori-Colorizer/)を参照してください。

## 設定

`Edit > Project Settings > Irodori Colorizer` で以下を調整できます。

- 有効 / Project ウィンドウ / Hierarchy ウィンドウの切り替え
- 行全体を塗る / 塗りの濃さ / 選択行は塗らない
- 文字色の自動判定 / 文字色（固定）/ ラベル位置
- 用途別プリセットの有効 / 無効
- 内蔵ラベルの色・名前・表示状態の変更とリセット
- カラーコード（Hex）による独自ラベルの追加・編集・削除

各項目の詳しい説明は[使い方ドキュメント](https://ghp.maaaaa.net/Irodori-Colorizer/)を参照してください。
